# 知流 ZhiFlow — 项目框架概述

> 一个面向个人内容创作者与行业从业者的 AI Agent 内容生产与知识沉淀工作台。

知流（ZhiFlow）不是一个简单的"AI 写文章工具"，而是围绕真实内容生产流程设计的本地化工作台。它希望把每天分散在新闻、网页、文档、聊天记录和笔记里的信息，转化为可复用的选题、文章、图卡文案和知识资产。

---

## 一、项目定位

品牌名：知流 KnowFlow  
归属：by Pigc W  
副标题：让 Obsidian 知识库自己长出来

一句话定位：知流 KnowFlow by Pigc W 是一个面向 Obsidian 的本地 AI 知识库增长工具，可以自动跟踪信息源、筛选关键内容、生成结构化笔记，并持续沉淀为可复用的个人知识资产。

---

## 二、核心功能

1. **资讯整理**：将每日新闻、网页摘要、手动输入的资料整理成统一格式
2. **内容分析**：通过 Agent 对输入内容进行二次加工（判断新闻价值、提炼行业影响、识别传播角度）
3. **文章生成**：根据不同内容类型生成对应文案（AI 资讯速递、能源/电力日报、行业观察文章、公众号文案等）
4. **公众号排版辅助**：针对微信公众号阅读习惯进行优化（短段落、强标题、去除 AI 味等）
5. **知识库归档**：将生成内容、选题、素材和已发布文章沉淀到本地知识库

---

## 三、Agent 工作流设计

```text
原始输入
  ↓
采集 Agent
  ↓
分析 Agent
  ↓
写作 Agent
  ↓
排版 Agent
  ↓
归档 Agent
  ↓
本地知识库 / 公众号素材 / 图卡文案
```

## 六、隐私与本地化说明

知流优先面向本地化和个人使用场景设计。对于个人知识库、行业资料、未发布文章等内容，建议优先使用本地存储和可控模型服务，避免将敏感资料直接上传到不可控平台。
